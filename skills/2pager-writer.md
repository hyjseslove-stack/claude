# 2pager-writer

2페이저(2-Pager) 문서를 작성하는 스킬입니다.

## 개요

2페이저는 아이디어, 제안, 프로젝트를 2페이지 이내로 간결하게 요약하는 문서 형식입니다.

## 구조

### 페이지 1
- **제목**: 명확하고 간결한 제목
- **문제 정의**: 해결하려는 문제 설명
- **제안 솔루션**: 핵심 아이디어 및 접근 방식
- **주요 이점**: 3-5개의 핵심 장점

### 페이지 2
- **구현 계획**: 주요 단계 및 마일스톤
- **리소스 요구사항**: 필요한 인력, 시간, 비용
- **리스크 및 대응**: 예상 위험과 완화 전략
- **성공 지표**: 측정 가능한 목표

## 작성 가이드라인

1. 간결하게 작성 (불필요한 내용 제거)
2. 핵심 메시지를 먼저 전달
3. 시각적 요소 활용 (표, 다이어그램)
4. 독자 관점에서 작성
5. 실행 가능한 내용 포함

## 사용 예시

```
프로젝트 제안, 기능 요청, 비즈니스 케이스, 기술 설계 문서
```
